# 📊 Project Overview

**Customer Churn Analysis & Intelligence** is an end-to-end Data Analytics and Machine Learning project designed to understand customer behavior, identify churn patterns, measure business impact, and support customer retention decisions.

The project combines:

- 🐍 Python
- 🐼 Pandas
- 🔢 NumPy
- 📊 Matplotlib
- 🎨 Seaborn
- 🗄️ SQLite
- 🧮 SQL
- 📈 Statistical Analysis
- 🤖 Machine Learning
- 📊 Power BI
- 🚀 Streamlit

The complete workflow transforms raw customer data into:

> **Data → Analysis → Insights → Prediction → Business Decision**

---

# 🏢 Business Context

Customer churn occurs when an existing customer stops using a company's product or service.

For subscription-based businesses such as telecom companies, losing customers can directly affect:

- Revenue
- Customer Lifetime Value
- Recurring Revenue
- Customer Acquisition Cost
- Business Growth
- Customer Satisfaction

This project represents a **Telecom / Subscription-Based Customer Business**.

Customers use services such as:

- 📡 Internet Service
- 📱 Phone Service
- 📺 Streaming Services
- 🔐 Online Security
- ☁️ Online Backup
- 💻 Device Protection
- 🛠️ Premium Technical Support

The company wants to understand:

> **Who is churning, why they are churning, and which customers should receive retention attention?**

---

# 🎯 Business Problem

The business is experiencing customer attrition and needs a data-driven approach to understand churn.

The analysis focuses on answering:

### 👤 WHO?

Which customers are more likely to churn?

### ❓ WHY?

What customer characteristics and service patterns are associated with churn?

### ⏳ WHEN?

During which customer tenure or contract periods does churn become more prominent?

### 💰 IMPACT?

How much revenue may be exposed because of customer churn?

The project aims to:


```sql
-- Customer count by status

SELECT
    Customer_Status,
    COUNT(*) AS Customer_Count
FROM customer_data
GROUP BY Customer_Status;
```
