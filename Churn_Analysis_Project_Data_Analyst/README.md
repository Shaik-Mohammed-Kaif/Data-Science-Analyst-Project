📌 Project Overview

Customer churn is one of the most important business problems for
subscription-based companies.

When customers stop using a company's services, the business can lose:

💰 Recurring revenue

👥 Customers

📈 Customer Lifetime Value

🤝 Long-term customer relationships

📊 Business growth opportunities

This project presents an end-to-end Customer Churn Analytics and
Prediction system designed to understand customer behavior, identify
churn patterns, analyze revenue risk, and predict customers who are likely
to churn.

The project combines:

Python + Pandas + NumPy + SQL + SQLite + Machine Learning + Power BI + Streamlit

The complete workflow moves from raw customer data to business-ready
insights and predictive analytics.

🏢 Business Context

This project represents a Telecom / Subscription-Based Customer
Business.

Customers use different telecom services such as:

📱 Phone Services

🌐 Internet Services

📺 Streaming Services

🔐 Online Security

☁️ Online Backup

🛡️ Device Protection

🛠️ Premium Technical Support

Customers may discontinue their services because of:

High monthly charges

Short tenure

Contract type

Service problems

Payment issues

Poor customer experience

Lack of support

Limited service usage

Customer dissatisfaction

The business wants to identify why customers leave, which customers
are at risk, and how the company can reduce churn.

🎯 Business Problem

The company is experiencing customer churn and wants to understand the
underlying customer behavior.

The central business questions are:

Why are customers leaving?

Which customer segments have higher churn?

Which customers are at higher risk of leaving?

How much revenue is potentially at risk?

The analysis transforms raw customer data into actionable business
intelligence.

🎯 Project Objectives

The major objectives of this project are:

Analyze customer demographics.

Analyze customer subscription behavior.

Study customer tenure.

Understand service usage patterns.

Analyze customer status and churn.

Identify high-risk customer segments.

Analyze churn by contract type.

Analyze churn by payment method.

Analyze churn by internet and phone services.

Study churn across states.

Analyze customer revenue.

Perform SQL-based business analysis.

Build churn prediction models.

Create Power BI dashboards.

Create interactive Streamlit dashboards.

Generate business recommendations.

💡 Key Business Questions

This project focuses on answering questions such as:

What is the overall customer churn rate?

Which customer groups have the highest churn?

Does customer tenure influence churn?

Which contract types experience higher churn?

Which payment methods are associated with churn?

🚀 How to Run

1️⃣ Clone the Repository

git clone https://github.com/Shaik-Mohammed-Kaif/Data-Science-Analyst-Project.git

2️⃣ Navigate to the Project

cd Data-Science-Analyst-Project
cd Churn_Analysis_Project_Data_Analyst

3️⃣ Install Dependencies

pip install -r requirement.txt

4️⃣ Open Jupyter Notebooks

jupyter notebook

Then open:

Churn-Analysis-IPYNB/

🌐 Run Streamlit Dashboard

Navigate to:

cd Streamlit_And-PowerBI-Dashbord-Churn-Analysis

Run:

streamlit run Stream_app.py

or:

streamlit run master_churn_dashboard.py

📊 Project Outcome

This project demonstrates a complete Data Analytics workflow from raw
customer data to business intelligence and predictive analytics.

The final system provides:

Data → Analysis → SQL → ML → Visualization → Dashboard → Insights

The goal is not only to identify customers who churned, but also to
understand why churn happens, where it happens, which customers are
most valuable, and which customers should receive retention attention.
