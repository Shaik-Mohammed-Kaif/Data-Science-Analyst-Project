# 📌 Project Overview

**YouTube Trending Videos Analytics** is an end-to-end Data Science and Business Intelligence project designed to analyze YouTube trending video data.

The project combines:

- 🐍 Python
- 🧹 Data Cleaning
- 📊 Exploratory Data Analysis
- 🗄️ SQL
- 🧠 NLP / Text Feature Engineering
- 📈 Statistical Analysis
- 📉 Interactive Visualization
- 🎨 Streamlit
- 📊 Plotly
- 🗃️ SQLite

The objective is to transform raw YouTube video data into meaningful business insights related to:

> **Reach → Engagement → Content → Publishing Strategy → Channel Performance**

---

# 🎯 Business Objectives

The project focuses on answering important business questions:

- Which videos generate the highest number of views?
- Which channels consistently perform well?
- Which categories receive the highest audience reach?
- Which categories have stronger engagement?
- What publishing time performs better?
- Does publishing on weekends impact performance?
- Does video quality influence views?
- Does caption availability influence engagement?
- Does title length relate to video performance?
- How do tags and hashtags relate to content visibility?
- Which video duration performs best?
- Which channels combine high reach and engagement?
